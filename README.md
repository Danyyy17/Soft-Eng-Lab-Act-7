# Soft-Eng-Lab-Act-7
## Project Overview

This project provides a complete end-to-end interface for staff at River Valley Eye Center to manage daily clinic operations:
- **Patient Registration & Medical Records:** Captures patient demographics, valid ID uploads, and PhilHealth memberships while executing real-time duplicate checking via fuzzy matching.
- **Appointment Scheduling:** Handles booking workflows with automatic duration calculated from selected procedures and real-time provider/room conflict detection.
- **Inventory Management:** Records stock transactions (Stock In / Stock Out), enforces low-stock reorder point indicators, and manages supplier receipts.
- **Reports & Data Filtering:** Allows staff to search and filter appointments by date, status, and provider, exporting filtered results in CSV or JSON formats.
